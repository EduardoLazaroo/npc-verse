## PASSO 1️⃣: Preencher Senha MySQL no .env

Abra `.env` e procure por:
```
DB_PASS=
```

Mude para sua senha MySQL real:
```
DB_PASS=sua_senha_aqui
```

**Salve o arquivo!**

---

## PASSO 2️⃣: Criar Schema MySQL (SE AINDA NÃO TIVER)

Abra terminal/cmd e execute:

```bash
mysql -u root -p < models/sql.sql
```

Será pedida a senha MySQL. Digite.

**Validar que funcionou:**
```bash
mysql -u root -p npcverse -e "SHOW TABLES;"
```

Deve retornar:
```
+----------------------+
| Tables_in_npcverse   |
+----------------------+
| interactions         |
| npcs                 |
| story_log            |
+----------------------+
```

Se mostra isso: ✅ BD pronto!

## Resumo Técnico (Pro Referência)

**Fluxo da App:**

```
Frontend (localhost:5000)
    ↓
Flask app.py
    ├─ init_qdrant() → Conecta ao Qdrant Cloud (primeira vez baixa modelo)
    ├─ GET /npcs → Busca do MySQL
    ├─ POST /register_npc → Salva NPC no MySQL
    ├─ POST /interact_npc → Processa interação:
    │   ├─ Busca memórias no Qdrant
    │   ├─ Busca histórico no MySQL
    │   ├─ Chama OpenAI GPT-4o-mini
    │   └─ Salva interação no MySQL
    └─ GET /story_log → Retorna histórico

MySQL npcverse:
  - npcs: lista de personagens
  - interactions: histórico de conversas
  - story_log: narrativa geral

Qdrant Cloud:
  - Coleção "npc_memory" (embeddings 384-dim)
  - Busca por similaridade de contexto
```

## Se Algo Quebrar

### ❌ "Access denied for user 'root'"
→ Verifique `DB_PASS` no `.env`. Está preenchido?

### ❌ "Table 'npcverse.npcs' doesn't exist"
→ Execute: `mysql -u root -p < models/sql.sql`

### ❌ "Connection timeout on Qdrant"
→ Primeira vez demora (download do modelo). Tente novamente alguns segundos depois.

### ❌ "Port 5000 in use"
→ Execute: `netstat -ano | findstr :5000`
Depois: `taskkill /PID <PID> /F`
